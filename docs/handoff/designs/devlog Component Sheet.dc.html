콜아웃

4종 맨 위로 ↑

옅은 면 + 좌측 4px 바 + 채운 원 아이콘. 글 상세 본문에서 밀도를 끊는 장치다.

정보 — 콘텐츠 1016 + 좌우 32 = 컨테이너 1080. 1144는 브레이크포인트이지 컨테이너 폭이 아니다.

주의 — 검정을 하드코딩하지 않는다. 다크 모드에서 페이지 배경과 같아진다.

정리 — 줄이는 것은 제목 계열뿐이다. 읽고 스캔하는 것은 그대로 둔다.

오류 — 상대 시간을 쓰지 않는다. SSG에서 빌드 시점에 굳어 거짓말이 된다.

패딩 14×16 · 라운드 10 · 좌측 바 4px · 원 25px는 텍스트 단계 채움 + 흰 글리프 15px · 좌측 바 4px는 글자가 없으므로 기본색 · 본문 13.5 / 1.7
