# 글 상세 `/posts/[slug]`

읽기 화면. 문서 톤. 긴 글을 편하게 읽는 것이 목적이다.

공용 규칙은 `../README.md`.

## 구조

```
스크롤 진행 바 3px
─────────────
제목 32 · 메타 한 줄 · 구분선
본문 8열(671) 40 들여씀   |   목차 10~12열 sticky
─────────────
태그 · 이전·다음
```

## 레이아웃 매핑

| 요소 | 래퍼 | 값 |
|---|---|---|
| 2열 | CSS grid | `minmax(0,711px) minmax(0,239px)` · gap 66 |
| 본문 열 | `VStack gap={5}` | `padding-left: 40` · `min-width: 0` |
| 제목 | `Heading level={1}` | 32 / 26 |
| 메타 줄 | `HStack gap={2}` | 12px · 분류 축은 전부 링크 |
| 목차 | `VStack gap={0.5}` | sticky `top: 74` |
| 읽기 본문 | `Text as="p"` | **17 / 1.75 · 모바일도 유지** |
| 소제목 | `Heading level={2}` | 21 / 19 + 번호 배지 |

**메타 한 줄**: `2026.08.03 · 회고 · Audemodo · FE · 12분`
분류 축은 전부 링크다 — 읽기 화면에서 탐색으로 돌아가는 유일한 경로.
모바일에서는 **항상 밑줄**을 붙인다. 호버가 없으니 색만으로는 링크임을 알 수 없다.

### 반응형 — 목차가 형태를 바꾼다

| | 1144 이상 | 1143 이하 |
|---|---|---|
| 목차 | 우측 sticky 239 | **본문 위 접이식** (기본 접힘) |
| 본문 | 8열 671 | 전폭 최대 671 · 가운데 |

근거: 본문 671을 지키려면 목차 239 + 간격 66 + 여백 64 = 1040px 이상이 필요하다.
**새 브레이크포인트를 만들지 않고 1144를 쓴다.**

1144 경계에서 본문이 가로로 한 번 이동한다. 없애려면 「본문 1~8열」 규칙을 깨야 하므로
그대로 둔다.

## 본문 장치

| 장치 | 사양 |
|---|---|
| 콜아웃 3종 | 옅은 면 + 좌측 4px 바(기본색) + 원 25px(텍스트 단계 채움 + `on-fill` 글리프 15px) · 본문 13.5 / 1.7 · 라운드 10 |
| 형광펜 2색 | `linear-gradient(transparent 55%, <hl> 55%)` · **글자색 `hl-ink` 명시** |
| 소제목 번호 배지 | 26px · 파랑 → 초록 → 코럴 순환 · 색에 의미 없고 리듬이 목적 |
| 코드블록 | 면 `code-bg` · 헤더 `code-head` (파일명 + 복사 버튼) · 줄 강조 `code-mark` + 좌측 2px 기본색 |
| 인용 | 좌측 3px 기본색 파랑 + SUITE 19 / 17 · 색 `text-primary` |
| 접이식 토글 | 곁가지 설명 |

**코드블록 배경을 검정으로 하드코딩하지 않는다.** 다크에서 페이지 배경과 같아진다.
**신택스 색은 하이라이터 테마가 정한다.** 직접 만들지 않는다.

## 이 화면 고유 계산

- **읽는 시간** — 본문 글자 수에서. 손으로 적지 않는다.
- **스크롤 진행 바** — 3px · 문서 높이 대비 스크롤 위치.
- **목차 활성 항목** — 현재 화면에 걸린 소제목. 읽는 위치를 따라 진해진다.
- **이전·다음** — 날짜 순 인접. `seriesOrder`가 있으면 시리즈 내 다음 편을 함께.
