## 시트에만 해당하는 규칙

### 사양 캡션은 시트만의 것

각 부품 아래 작은 글씨(11.5px `secondary`)로 hex · 열 번호 · 타이밍을 적는다.
**제품 화면에는 넣지 않는다.**

### 색 견본은 색 자체가 콘텐츠다

**이 시트를 토큰으로 바꾸지 않았다.** 스와치가 라이트 팔레트를 보여주는 견본이라,
토큰으로 바꾸면 다크에서 「#3655FF」라고 적힌 칸이 다른 색으로 칠해진다.

같은 이유로 기본색 띠 위의 이름과 hex는 **흰 칩 위에 올렸다** —
면은 기본색 그대로 남고 글자는 흰 면 위에 앉는다.

다크 팔레트는 별도 열로 문서화한다. 「라이트와 다크를 나란히」 절이 그것이다.

### `auto-fit` 규칙의 적용 대상이 아니다

**시트는 견본 나열이라 흘러도 무방하다.** 3+1이 제품 화면에서는 고아지만
카탈로그에서는 「목록이 거기서 끝났다」일 뿐이다.

**예외 하나**: 「라이트와 다크를 나란히」는 견본 나열이 아니라 **비교 구조**라
2열로 못 박았다. 4열이면 카드당 110px로 띠 안의 hex가 읽히지 않는다.

## 구현할 때 이 시트에서 가져갈 것

- 색 매핑 표 → `reference/devlog-theme.css`
- 타이포 17단계 → 공용 문서의 표
- Token 4갈래 → **테두리가 인터랙션 신호다.** 없으면 읽는 것, 있으면 누를 수 있는 것
- 버튼 매트릭스 → 3단계 × 4상태
- 진행 표시 3종 → 단계 / 비율 / 구성
