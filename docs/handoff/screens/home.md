# 홈 `/`

**포트폴리오가 아니라 블로그다.** 진열하지 않고 말을 건다.

공용 규칙은 `../README.md`.

## 구조 — 섹션 여덟, 면을 아홉 번 교차

```
1 히어로                        흰
2 최신 글 — 가로 캐러셀          흰
3 만들고 있는 것 — 잔디 + 프로젝트  회색
4 세 갈래로 쌓인다 — 분포 + 카테고리 흰
5 묶어서 읽기 — 시리즈 + 주제 묶음  회색
6 자주 쓴 것 — 태그 클라우드       흰
7 쌓인 것 — 월별 막대             회색
8 하단 카드 셋                   흰
```

**섹션마다 형태가 달라야 한다.** 전부 카드 그리드면 밋밋해진다 —
캐러셀 · 검정 카드 · 분포 막대 · 칸 막대 · 클라우드 · 세로 막대 · 가로형 카드로 돌린다.

## 히어로 — 우측을 비운다

```
지금까지 [여섯 개]를 만들었고, [서른네 편]을 썼다.     ← 44 / 29 · 대괄호에 파랑
그중 [열 편]은 막혔던 이야기다. 모든 결정은 …          ← 15 / 1.7 · 코럴 텍스트 단계
```

**숫자가 문장 안에 색으로 박힌다. 통계가 아니라 문장이다.**
문장 안은 한글 숫자, 데이터는 아라비아.

**우측을 비운다.** 문장 하나뿐이면 컨셉이 가장 순수하게 드러난다.
지표 4카드는 **넣지 않는다** — 히어로 문장과 중복이고 「양 자랑」에 가깝다.
세로 여백 88 / 84 (모바일 52 / 48).

둘째 줄 「열 편」은 코럴 **텍스트 단계**를 쓴다. 15px에 기본색은 3.3:1로 미달한다.

## 레이아웃 매핑

| 섹션 | 래퍼 | 데스크톱 | 모바일 |
|---|---|---|---|
| 캐러셀 | `HStack gap={5}` + `overflow-x: auto` | 카드 239 | **유지** — 스와이프가 원래 동작 |
| 프로젝트 | CSS grid | 3열 | 1열 |
| **잔디 카드** | `VStack` / `HStack` | **세로** (잔디 위 · 텍스트 아래) | **가로** (잔디 좌 · 텍스트 우) |
| 카테고리 | CSS grid | 4열 × 2 | **2열 × 4** |
| 시리즈 | CSS grid | 2열 | 1열 |
| 태그 클라우드 | `HStack wrap` + `align-items: baseline` | gap 10 / 20 | 동일 |
| 월별 막대 | `HStack align="flex-end"` | 높이 120 | 동일 |
| 하단 카드 | CSS grid | 3열 | **1열 가로형** |

### 캐러셀

`scroll-snap-type: x mandatory` + **`scroll-padding-inline: 32px`** (모바일 20).
스냅 기준선을 거터 안쪽으로 옮겨야 첫 카드가 정렬선에 맞는다 —
없으면 로드 시 `scrollLeft: 32`로 밀려 있다.

카드 — 썸네일 239 × 134 + kind 라벨 + 날짜 + 제목 17 / 1.45 (2줄 클램프).

### 잔디 카드 — 형태가 바뀐다

**검정 카드**(`--devlog-solid`)로 잔디를 넣는다. 칸 9 × 9 · 라운드 2 · gap 3 ·
7행 세로 흐름.

| | 데스크톱 | 모바일 |
|---|---|---|
| 방향 | 세로 (잔디 위) | 가로 (잔디 좌) |
| 칸 수 | 91 (열세 주) | **84 (열두 주)** |

**모바일 카드는 낮아 잔디가 세로로 안 들어간다.**

**문구가 그리는 칸 수를 말해야 한다.** 91칸이면 「열세 주 · 91일 중 80일」,
84칸이면 「열두 주 · 84일 중 73일」. 그림과 문장이 같은 배열에서 나온다.

램프 4단계 — 빈 칸은 `--devlog-solid`보다 밝은 회색, 나머지는 초록 3단계.
**다크에서도 이 카드는 어두운 채로 남는다** (`--devlog-solid`). GitHub 잔디는
원래 어두운 판이라 밝아지면 잔디로 안 읽힌다.

### BE 0편 — 점선 카드

카테고리 8칸 중 `BE`는 글이 0편이다.

**감추면 「BE는 안 한다」로 읽히고, 점선으로 두면 「아직 안 썼다」로 읽힌다.**
취업 목표가 FE·BE 둘 다이므로 정직한 쪽이 낫다.

- 점선 `1px dashed border-emphasized` · 링크 없음 · 숫자와 설명 `secondary`
- **누를 곳이 없는 것이 「아직 없음」의 정직한 형태다**

## 이 화면 고유 계산 — 전부 코퍼스에서

| 표시 | 계산 |
|---|---|
| 히어로 세 숫자 | 프로젝트 수 · 글 수 · 트러블슈팅 수 (한글 수사 변환) |
| 분포 막대 | kind별 비율 — 합이 100%가 되어야 한다 |
| 카테고리 8칸 | kind 4 + track 3 + 태그 1의 실제 편수 |
| 캐러셀 | 날짜 내림차순 6편 |
| 태그 클라우드 | `tag` + `stack` 빈도 → 12~27px 선형 매핑 |
| 월별 막대 | 월별 편수 · 최대값 기준 정규화 · 시간 순 |
| 「전부 읽으면 N시간」 | 글 수 × 평균 12분 |
| 시리즈 진행 | 쓴 편수는 코퍼스에서, 계획 편수는 수기 |
| 주제 묶음 편수 | 큐레이션 목록의 길이 |

**주제 묶음은 태그와 다를 수 있다.** 사람이 고른 것이고, 그게 태그 클라우드와
별개 섹션인 이유다. 같으면 두 섹션이 중복이다. 다만 숫자는 목록 길이에서 나와야 한다.
