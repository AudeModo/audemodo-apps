# 프로젝트 목록 `/projects`

만든 것 여섯 개. **필터를 두지 않는다** — 여섯이 한 화면에 다 보이면 필터가 줄여줄 것이 없다.

공용 규칙은 `../README.md`.

## 구조

```
제목 「프로젝트」 + 6 · 부제
카드 3열
───── 회색 면 ─────
타임라인 — 시작 순
```

## 레이아웃 매핑

| 요소 | 래퍼 | 값 |
|---|---|---|
| 카드 격자 | CSS grid | 3열 / 1열 · gap 20 |
| 카드 | `Card padding={4.5}` | 라운드 12 · 패딩 18 |
| 이름 | `Heading level={3}` | 21 / 19 · −.025em |
| 설명 | `Text color="secondary"` | 12.5 / 1.6 · `min-height: 40` |
| 상태 | `HStack gap={1.5}` | 점 7px 기본색 + 라벨 11px `primary` |
| 스택 | `Text type="supporting"` | 11px · .02em |
| 지표 줄 | `HStack gap={2}` + `Divider` 위 | 12px tabular-nums |

### 카드에 색을 쓰지 않는다

**로고도 이니셜 마크도 만들지 않는다** — 역사가 없어 아무것도 증명하지 않는다.
이름 21px가 카드의 주인공이다.

유일한 색은 상태 점 7px. 「색은 점에만, 라벨은 본문색」 규칙의 적용이다.

지표 줄의 링크(`글 18` · `배포↗`)도 **무채색 + 옅은 밑줄**이고 호버에서 진해진다.
색을 뺀 자리를 밑줄이 메운다.

### 카드 호버 — 이름에 밑줄

**카드에 커서를 올리면 이름에 밑줄이 그어진다.** 자손 선택자가 필요하다:
`.card:hover .name { background-size: 100% 2px }`

시안에서는 인라인 스타일로 자손 규칙을 만들 수 없어 투명 `::before` 오버레이로 우회했다.
**제품에서는 걷어내고 자손 선택자를 쓴다.** 겹치는 링크에는 `z-index`가 필요 없어진다.

### 타임라인 — 카드와 정렬 기준이 다르다

카드는 **중요도 순**, 타임라인은 **시작 순**. 같은 여섯을 다른 축으로 보면
무엇이 겹쳤고 무엇이 이어졌는지가 드러난다.

| | 데스크톱 | 모바일 |
|---|---|---|
| 축 | 위에 월 축 02~08 | 없음 |
| 이름 | **막대 안** | **좌측 84px 열** |
| 기간 | — | **우측 `02~03` · `05~`** |
| 막대 | 28px · 라운드 6 | 8px · 라운드 9999 |

진행 중인 것은 **오른쪽 끝이 열려 있다** (그라디언트로 페이드).

**막대 색은 라벨이 막대 안에 있는지로 정해진다.** 규칙은 하나이고 조건의 답이 분기마다 갈린다:

- 데스크톱 — 이름이 막대 안 → **텍스트 단계** (흰 글자 7:1 이상)
- 모바일 — 막대에 글자 없음 → **기본색**

색에 의미는 없고 구분이 목적이다. 6칸 순환: 파랑 · 코럴 · 노랑 · 초록 · 검정 · 회색.
회색은 `secondary`를 쓴다 — `disabled`가 아니다. 막대는 비활성이 아니다.

## 이 화면 고유 계산

- 카드 정렬 — 중요도(수기) / 최근 활동 / 시작 순 중 선택
- 타임라인 격자 — 월 축 7칸에 `grid-column: start / end` 매핑
- 지표 — 글 수는 코퍼스에서, 커밋·최근 활동은 GitHub API 빌드 타임
